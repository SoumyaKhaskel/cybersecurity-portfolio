# Soumya Khaskel Portfolio

A static portfolio built with HTML, CSS, and vanilla JavaScript.

## Preview locally

Open `index.html` in a browser, or serve this folder with the VS Code Live Server extension to preview the site with local asset paths.

There is no build command or package installation required.

## Main files

- `index.html` contains the page content and structure.
- `styles.css` contains the visual design and responsive layouts.
- `script.js` contains the small interactive features.
- `assets/` contains the resume, certificates, project evidence, and profile images.

## Deployment

This project can be deployed as a static site. Connect the GitHub repository to Cloudflare Pages, leave the build command empty, and set the output directory to the repository root.
